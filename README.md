# Direct Order 27: alpha test

Thanks for testing! This repository holds the packaged alpha build only.

## Install (one step)

Open a terminal, paste this line, and press Enter:

```
curl -fsSL https://raw.githubusercontent.com/PiercingXX/Alpha-test-DO27/main/install.sh | bash
```

It checks your system, installs anything missing (it may ask for your password once), downloads the game, and adds **Direct Order 27 (alpha)** to your app menu.

The game updates itself: each time you start it, it checks for a new alpha build and installs it first.

## What you need

- Arch Linux or CachyOS (64-bit)
- A graphics card with Vulkan: an NVIDIA RTX 2080 or newer, or an AMD RX 6000 or newer
- An NVMe SSD with 20 GB free
- 16 GB of RAM

## Play

Open **Direct Order 27 (alpha)** from your app menu, or type `do27` in a terminal.

## Reporting problems

Crash and session logs are sent to the dev team automatically. You can also open an issue here or post in the alpha channel on Discord.

## What the alpha logs

By playing the alpha you agree that these are sent to the dev team with every session and crash:

- your alpha username (you choose it on first start; it can't be changed during the alpha)
- your IP address
- your system: Linux distribution, kernel, graphics card and driver, memory
- the game's session log, crash reports and performance numbers

## Uninstall

```
do27-uninstall
```

This is a test build: please don't share it outside the alpha.
